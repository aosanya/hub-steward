# Demo agencies

Nine synthetic agencies, eight of them a folder with an `agency.json` template and one a single file, `municipality.json`, all importing with `POST /instances/import`. The eight folders are also the console's Create Hub templates; the municipality is not offered there and has no copy under `code/console/public/templates/`, so it is loaded by `POST /instances/import` alone. Every organization, person, number and address in them is invented, and each template marks itself illustrative. How to load one is in [Load the demo agencies](../documentation/3.%20implementation/guides/load-demo-agencies.md).

The Siaya computer lab is the only folder with documents, which its agent is meant to answer from, in English, Swahili, German and Hungarian. The Siaya Farmers' Group is the one the market and group-order journeys follow. The other six folders and the municipality show what else the same platform runs.

[municipality.en.json](municipality.en.json) is the same municipality in English: the same ids, codes, roles, workflows and steps, with every text translated and the town's own names left as they are. It is for trying the workflows without reading Hungarian; the tests and walks read the Hungarian file.

The counts and module lists are read from each `agency.json`; the modules column lists only the modules a template enables.

The five organization templates (clinical research, grid utility, freight, mobile money, drone spraying) each end with a Risk review workflow and a Risk owner role (the drone service spells it Risk Owner). Only the municipality switches on the risk manager module, which the API can mount.
