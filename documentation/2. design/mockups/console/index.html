Every page file of the console mockups, one card each, grouped as the console menu groups them. Open a file to see its screens. The side bar of every file links to the other files, so the whole set can be clicked through. Every page has a header strip across the top (brand, hub switcher, breadcrumb, language) and three columns under it: the menu on the left, the content in the middle and the chat on the right, which collapses to a rail.

The console routes are /start, /login, /create and /hubs before a hub is open, and /h/:hubId/<page id> for every page inside a hub. A card shows the page id as that route. A file that is a form, a detail or a state of another page shows that page's route. 75 page files, 449 screens.

The console shows one agency at a time, and its menu follows the hub kind: Farmers, Lab or Riders. Each menu below is what the side bar shows at rest; a row with sub-pages opens them when the page or one of its sub-pages is current. Network is hidden in the console menu, and Farm orders and Produce are in no menu.
