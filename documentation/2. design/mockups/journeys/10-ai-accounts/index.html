AI accounts

An agency holds the models its agents use and knows that each one works and what it has used.

1. Adds a model

On Models the manager chooses Add a model and picks a provider: Meta Model API, Meta open weights (Baseten, Modal or your own server), Hugging Face, Claude, or Other (OpenAI-compatible). A second list offers the standard models for that provider, and Other model… asks for the model's name. Meta open weights and Other also ask for a base address, which for Other must start with https://; Meta Model API's is prefilled. The manager types only the key, into a field named for the provider. After Save key the button reads Saved and the field empties. The studio then asks the provider which models the key can use and lists them above the standard ones, with a Refresh models link; if the list cannot be read it says so, shows the standard list and offers Try again. Save model adds it. Models opens with the notice "Model added" and lists each model with its provider, model id, key and the number of roles that use it. A hub holds several models and adding one never replaces another. The key is never shown again. Only an owner can add a model or set a key.

2. Tests the model

On the model's page, in Key and test, the manager chooses Test connection. One short request goes to the provider with the hub's key, and the line beside the buttons names the provider and the time, for example "Meta Model API answered in 640 ms", or reads "Not working" with one plain reason: no key is set, the model refused the key, the model could not be reached, or the model answered with an error. The last result stays on the model, and the key never appears in it. The same page changes the model, keeping the key, and removes it after a confirmation ("Agents that use it will have no model until you choose another. The key is deleted.").

3. Sets the model's limits

In Limits the manager sets any of seven limits: tokens per call, day, week and month, and requests per minute, day and week. Each has an Applies switch, and with the switch off its field reads "No limit". Save limits keeps them, and they cap every AI role that uses the model. Owners and staff seats can do this.

4. Sees usage

In Usage one table shows the use against each limit that applies: what is used, the maximum and the share. A second table splits this month's use by AI role, one row per agent. A reached limit reads as one plain sentence, for example "this account's monthly token limit is reached", and its row reads Reached. A staff seat sees Limits and Usage but not Key and test.
