The journey

Design a chat workflow

The hub manager makes a workflow that opens straight into a chat with an agent, boxes the chat in to what it talks about, the tools it may call and the workflows it may lead the person to, and tests it with the lines a made-up farmer says.

1. Sees the chat workflows

Workflows lists the farmers' agency's workflows as cards. The two that open in a chat, Buy inputs and Sell harvest, come first and carry a small chat icon before the name; each also shows the agent it chats with, here the Farmers' agent, beside its steps, roles and objectives. The other cards, such as Buy now and Group order, open in a form and carry no mark.

2. Adds a chat workflow

Add a workflow opens the Workflow tab with a name, what it is for and Opens in, A chat or A form; A form is chosen when the form opens, and choosing A chat is the only change on this tab. On the Steps tab of a chat workflow, step 1 is already there as the locked step Chat with an agent, open and empty, with its kind shown as a muted chip because it cannot be changed; more steps may be added after it. Saving puts the workflow in the draft, and Publish makes it live within 30 seconds.

3. Boxes the chat in

On the chat step the hub manager says who opens it, the agent it chats with, what it talks about, what it says first, up to three prompts, the tools it may call and the workflows it may start. Buy inputs is opened by the Farmer and chats with the Farmers' agent; it talks about "Buying farm inputs: what is on sale, shops and prices, group orders, things not listed, her orders."; it says first "What do you want to buy?" and offers the prompts I need fertiliser, I want hybrid maize seed 614 and I need something for pests. Can call is a list of tools in plain words, ticked one by one: See what is on sale, See shops and their prices, See group orders, Ask a shop, Put up a notice and See my orders are ticked; See buyers' prices, See group sales and Ask a buyer, which belong to selling, are not. Can start lists the agency's other workflows: Buy now, Group order and Find it are ticked; Sell now, Group sale, Approve a supplier and Change my share are not. The chat may call and start only what is ticked, and the agent steers the person politely back to what it talks about when she strays; that is built in, not a field. The farmer's side of this chat is in journey 13, step 1.

4. Tests the chat

Add a scenario, with Buy inputs picked from the Workflow list, where it is marked as opening in a chat, has the same three tabs. Actors holds one farmer, Farmer 1, who plays the chat step; the Farmers' agent, the Suppliers' agent and the System are there and read only. Blocks holds one block, because the workflow has one step: the lines the made-up farmer says, here I need fertiliser and Urea, and a Then line that names the workflow the agent should lead her to, picked from the chat's Can start list: Buy now, Group order or Find it. Run opens a report in which the Test agent says the lines into the chat and the Farmers' agent answers as it does for members. The table shows each answer, the tools it called, whether any was outside Can call, and whether the Then line held: here two of the six tools were called, none outside the list, and the agent led her to Buy now, which opens as a chat under the first.
